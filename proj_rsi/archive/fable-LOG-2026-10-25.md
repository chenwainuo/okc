### Where the spec was wrong

Fable wrote the mma operands as `A={lo.x, hi.x, lo.y, hi.y}`. PTX for `m16n8k16` puts a0 and a1 on row `lane>>2` and a2 and a3 on that row plus 8. `hi` is the row+8 vector, so it belongs in a2/a3, not a1. Shipping `A={lo.x, lo.y, hi.x, hi.y}` and `B={b.x, b.y}`. K is still permuted the same way on A and B (each lane's `uint4` covers 8 contiguous bf16 at `k0+8*(lane&3)`), which is legal because the dot product does not care which physical K lands in which instruction slot.

Accumulator store, which Fable did not specify, follows the PTX C/D map: for element i, row is `groupID` when i < 2 else `groupID+8`, col is `(lane&3)*2 + (i&1)`.

Decode m=16 pooler is already 14.30 µs against a 14.1 floor and an m=1 time of 13.95. The board win, if the kernel is good, is decode m=32. m=16 is in the same kernel so one check measures both. A regression there is reported, not papered over.

### Where the spec was adjusted

- qkv m=128: N/256=9, so CK=8 yields 72 CTAs, not 128. The spec's own CTA rule leaves it on r6. Not launching CK=16.
- Multicast mask is the M-pair's two cluster ranks. Constant `0b11` only names ranks 0 and 1, so every K-rank except 0 would complete the wrong barriers and hang.
- Empty-barrier arrival count stays 2, local consumers only. Multicast copies B into each CTA's own smem; remote empty arrives are not required and a count of 4 with no remote arrive deadlocks.
- `wgmma.wait_group 0` is inside the one K-loop `asm volatile`. A second asm spills the 128 accumulators.
- Barrier phases follow the r7 pipeline that already finished on this judge: no pre-arrive, producer waits only once the stage is reused.
- m=128 copies use the `shared::cta` forms r7 already ran. Multicast is only the m=256 B half-tiles.
- PTX: imm-trans 0 means K-major. `0, 0` is the right pair for `X[M,K] @ W[N,K].T`.
- Accumulator map is the r7 map extended from 8 groups to 32: register `v0+2*v1+4*v2`, row `base+8*v1`, column `2*(lane&3)+v0+8*v2`. r7's m64n64 store was numerically exact.
- Repack is in `prepare`, which is untimed. No bias. The experiment is valid on that assumption.
- 128B-swizzle descriptor base must sit on a 1024-byte boundary. Barriers occupy the first 1024 bytes; stage stride is 49152.
